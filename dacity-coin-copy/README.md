# Dacity Coin — static HTML copy (patched)

This is a static HTML snapshot prepared from the HTML supplied in the conversation. Image references have been changed to direct original image URLs to avoid depending on the original Next.js image optimizer. The page still loads its original CSS and JavaScript from `dacitycoins.com`, so it is not fully self-contained.

## Update the existing GitHub repository
1. Open your repository `broodxher-dot/dasiti-coin-copy`.
2. Click `index.html`, then the pencil icon (Edit this file), or choose **Add file → Upload files** to replace it.
3. Upload the new `index.html` from this archive and commit the change.
4. Vercel should redeploy automatically. If it does not, open the project in Vercel and choose **Redeploy**.

## Deploy
Vercel preset: Other. No build command is needed for the static HTML page.

## Limitations
This is not the original Next.js source project. Some interactions/animations may still fail because their original runtime and supporting assets are hosted by the original site. Use only assets you have permission to reuse.
